# AI Use Acknowledgement

Our group used generative AI tools during the development of this
project. These tools assisted with activities including brainstorming,
explanation of technical concepts, drafting and reviewing code,
debugging, generating test-case suggestions, improving documentation,
and language editing.

All AI-generated suggestions were reviewed, modified where necessary,
integrated and tested by group members. The group retained
responsibility for the system architecture, requirements interpretation,
implementation decisions, validation, final written content and
submitted source code. AI-generated output was not accepted without
human review and verification.

The prototype itself also integrates AI models as part of its intended
system functionality. The university-hosted Qwen model is used for
structured natural-language processing, and a separately hosted fallback
model is used when the primary service is unavailable. These runtime AI
components are part of the implemented prototype and are distinct from
the generative AI tools used to assist project development.

No API keys, passwords or other credentials are included in the
submitted source package. Each group member has reviewed this
acknowledgement and confirms that it accurately represents the group's
use of AI.
